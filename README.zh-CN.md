# stats-codex-monitor

基于开源 [Stats](https://github.com/exelban/stats) 的轻量原生 macOS 性能助手。保留 CPU、内存和磁盘的原生菜单，并新增 **SD** 状态、历史与诊断入口。

**当前状态：0.2.0/build2 实验性源码预览。** 新增合成数据文件往返与独立本地确认，仅允许打开活动监视器或短时间观察已有采集结果。CI 执行 Swift 测试和未签名编译，请检查对应提交的结果；原生界面、授权与中断验证仍待完成。本版本并非已公证发布版。

## 现在能做什么

- 复用 Stats 采集器：CPU/内存/swap 每 60 秒；磁盘容量和 CPU/内存进程排行每 5 分钟
- 系统内存压力事件可在轮询之间立即提示严重压力
- 本地保留最多 7 天经过清理的历史，按小时保存，限制记录数量
- CPU 超过 85% 持续 5 分钟、内存警告持续 3 分钟、内存严重压力立即触发规则
- 启动磁盘不足 20 GiB 提醒一次，低于 10 GiB 升级提醒；恢复后重新计算
- CPU/内存同一异常阶段有 30 分钟冷却；休眠、暂停和缺失数据不算持续异常
- 点击 **SD → Diagnose…**，先预览，再复制或导出诊断内容

## 与 dot / Codex 的边界

当前版本不会自动上传给 dot，也不会一键运行模型。请先检查导出的内容，再自行发送给 dot、Codex 或其他分析工具；只有你明确提交后才可能使用额度或产生费用。

导出最多包含近 30 分钟的 90 条读数和最近 12 条提醒，JSON 上限 64 KiB。包含数值和固定进程类别，不包含原始进程名、PID、命令行、环境变量、文件路径、设备序列号、账号信息或凭据。

诊断提示要求只提供建议，不运行工具或自动修复。此应用不能控制独立分析工具的权限，也不会执行其建议的命令。未使用私有接口、猜测的 URL scheme、凭据转接、远程指令监听或远程 shell。

## 编译

需要 macOS 12 或以上及完整 Xcode。Xcode 26.3 是初始计划验证环境，兼容性尚未认证。

```sh
./scripts/build-diagnostics.sh
```

脚本先运行真实 Swift 规则/隐私测试，再编译并使用本机临时签名。不自动安装、启动、设置登录启动或使用开发者凭据。产物为 `build/Build/Products/Release/Stats Diagnostics.app`。

请先完成 [Mac 验证清单](docs/MAC_VALIDATION.md)。不要运行上游 Makefile 的发布流程，它包含上游签名、公证和发布假设。

## 隐私与许可

- 后台不调用 LLM，不传输监控数据；上游更新和 Remote 功能关闭
- 本版本不启动可选传感器、蓝牙、网络、GPU、电池、时钟等模块，也不附带桌面小组件或特权风扇辅助程序
- 上游原始读数数据库已关闭，只保存经过清理的诊断历史
- 通知需通过 **SD → Enable local notifications…** 手动授权；无需通知权限也能查看状态和历史
- 本地目录：`~/Library/Application Support/StatsDiagnostics/`，仅当前用户可访问
- 应用运行时每分钟检查过期历史；关机、退出或休眠期间无法清理，会在下次运行/唤醒后继续。主动导出的文件不自动删除
- 独立应用标识与数据目录，不覆盖上游 Stats
